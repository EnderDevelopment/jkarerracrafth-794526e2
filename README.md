# MagicWandPlugin

MagicWandPlugin is a Minecraft plugin that adds a magic wand and skill system to your server. Players can use the magic wand to cast spells and activate various skills, enhancing their survival experience. The plugin includes a skill bar with multiple slots, each containing different skills such as healing, buffs, and fireballs. Players can level up their skills and use them in combat or exploration.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Start or restart your server to load the plugin.

## Use

1. Give a player a magic wand using the command `/magicwand`.
2. The player will receive a skill bar with 6 slots in their inventory.
3. Use the magic wand to cast spells and activate skills.
4. Press the Shift key to toggle the skill bar visibility.
5. Press the F key to attack with the skill bar.
6. Each skill has a cooldown and level requirement. Players must reach the required level to use a skill.
